# Программа генерации случайных паролей

Эта программа предназначена для генерации случайных паролей с заданным количеством символов. Пароли могут содержать буквы верхнего и нижнего регистра, цифры и специальные символы.

## Особенности

* Генерация случайных паролей заданной длины.
* Возможность использовать буквы верхнего и нижнего регистра.
* Возможность добавлять цифры и специальные символы.
* Простое и понятное консольное приложение.
* Наличие автоматических тестов с использованием `pytest`.

## Требования

Для использования программы необходим:

* Python версии **3.6 или выше**.

Проверить установленную версию Python можно командой:

```bash
python --version
```

## Установка

Склонируйте репозиторий:

```bash
git clone <>
```

Перейдите в директорию проекта:

```bash
cd <НАЗВАНИЕ_ПРОЕКТА>
```

При необходимости установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск программы

Для запуска программы выполните:

```bash
python main.py
```

После запуска программа предложит указать необходимые параметры для генерации пароля.

## Пример работы

```text
Введите длину пароля: 12

Сгенерированный пароль:
aG7!kP2@xQ9#
```

Каждый новый запуск программы может создавать новый случайный пароль.

## Запуск тестов

Тесты написаны с использованием библиотеки `pytest`.

Для установки `pytest` выполните:

```bash
pip install pytest
```

После установки запустите тесты из корневой директории проекта:

```bash
pytest
```

Если все тесты пройдены успешно, в консоли будет отображён соответствующий результат.
